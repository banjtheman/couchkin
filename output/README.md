# Public visual assets

These files help explain Couchkin's appearance and interface. They are not a substitute for footage of the project running on Twitch.

## Actual desktop screenshots

`couchkin-app-quick-picks.png`, `couchkin-app-creator.png`, and `couchkin-app-personality.png` were captured from the running packaged Mac app on October 30, 2026. They show the saved Riff companion and real controls. No paid session or public broadcast was started for these captures. The personality comparison remains explicitly labeled as a scripted example. These screenshots contain no credentials or overlay pairing URLs.

## Interface previews

The other nine images in `screenshots/` show the implemented quick-pick, customization, memory, and Twitch-connection interfaces using isolated browser fixtures. Names, memories, account identities, sign-in codes, and posting statuses shown in these previews are demonstration data. They do not establish that a live message was posted or a live memory was saved. Narrow-layout previews test responsiveness; the supported desktop application is currently macOS.

For the Devpost gallery, the desktop quick-pick and memory previews make the clearest overview images. The portrait customization and chat panels are better as detail images. Every included PNG is below the 5 MB upload limit; the suggested 3:2 aspect ratio is a recommendation, not the dimensions of every interface preview.

## Original visual concepts

`imagegen/01-stream-mockup.png` through `04-theme-attribute-creator.png` are generated design concepts, not application screenshots. They depict original characters and an illustrative stream composition. `05-native-codex-character.png` is an original transparent character generated through the signed-in Codex image tool during a runtime check.

`imagegen/06-couchkin-cover.png` is original brand artwork showing the couch-buddy idea. It is not a screenshot or a promise of a literal couch interface. Its exact generation prompt is recorded in [cover provenance](imagegen/06-couchkin-cover-prompt.md).

Generation methods and prompts are documented in [the provenance record](imagegen/prompt-manifest.md). Keep concept images clearly labeled if used in a project gallery.

Legacy private integration captures and the earlier generated speech sample are deliberately excluded from the public source export. See [verification](../docs/verification.md) for the observed checks and their limits.
